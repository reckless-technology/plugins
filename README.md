# Reckless Technology plugins

The downloads of the Reckless Technology plugins: twenty-one audio plugins, each a VST3, an Audio Unit on macOS and a
standalone app, for macOS 26 and later, Windows 10 and 11 (64-bit) and Linux (x64).

| | |
|---|---|
| macOS | [reckless-plugins-macos.pkg](https://github.com/reckless-technology/plugins/releases/latest/download/reckless-plugins-macos.pkg) |
| Windows | [reckless-plugins-win64-setup.exe](https://github.com/reckless-technology/plugins/releases/latest/download/reckless-plugins-win64-setup.exe) |
| Linux | [reckless-plugins-linux-x64.zip](https://github.com/reckless-technology/plugins/releases/latest/download/reckless-plugins-linux-x64.zip) |

The installer is the same whether you have a licence or not; the licence, which comes by email when you buy, opens
the full plugins. Every release is listed under [Releases](https://github.com/reckless-technology/plugins/releases),
with the user guide beside it.

The plugins, the licence and the support are at [recklesstechnology.com](https://recklesstechnology.com). This
repository holds the downloads alone: the plugins are proprietary software, licensed to their users under the end-user
licence each installer shows.
